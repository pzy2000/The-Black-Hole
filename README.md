# 事件视界 · EVENT HORIZON

广义相对论实时渲染的黑洞巡航游戏。画面中的每一个光子都在 GPU 上沿史瓦西时空的零测地线积分生成——引力透镜、光子环、吸积盘的多普勒聚束与引力红移全部是真实物理"算"出来的，不是贴图。

完整的游戏设计文档见 [PLAN.md](./PLAN.md)。当前进度：**M1「第一眼」完成**。

## 运行

```bash
npm install
npm run dev        # 开发服务器，打开 http://localhost:5173
npm run build      # 生产构建（输出到 dist/）
```

需要支持 WebGL2 的浏览器（Chrome / Edge / Safari 均可）。

## 操作

- 拖拽旋转视角，滚轮缩放（最近可贴近到 3.5 个史瓦西半径，可以钻进吸积盘平面）
- 右上角开关：自动巡航 / 画质三档 / 多普勒聚束「真实 ↔ 电影」
  - **真实**：盘一侧因相对论聚束白热发亮（与 EHT 拍到的 M87* 同一效应）
  - **电影**：《星际穿越》为观感人为调对称的同款处理

## 已实现的物理

- 零测地线光线步进（d²x/dλ² = −1.5·h²·x/r⁵），阴影、透镜、光子环、盘的上下像
- 吸积盘：Novikov–Thorne 温度轮廓、开普勒差速旋转湍流（域扭曲丝缕）、双相位流动避免噪声无限剪切
- 相对论多普勒因子 δ + 引力红移 √(1−Rs/r)，亮度按 δ³ 聚束，颜色沿黑体谱偏移
- 程序星空：三层网格哈希恒星（黑体色温着色）+ 银河带，均被透镜实时扭曲
