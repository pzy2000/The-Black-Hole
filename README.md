# 事件视界 · EVENT HORIZON

广义相对论实时渲染的黑洞巡航游戏。画面中的每一个光子都在 GPU 上沿史瓦西时空的零测地线积分生成——引力透镜、光子环、吸积盘的多普勒聚束与引力红移全部是真实物理"算"出来的，不是贴图。

完整的游戏设计文档见 [PLAN.md](./PLAN.md)。当前进度：**第一篇章 M0–M4 与第二篇章 M5–M8 全部完成**——14 关战役、三个真实黑洞巡礼、双结局、摄影模式、真实星表星空。

## 运行

```bash
npm install
npm run dev        # 开发服务器，打开 http://localhost:5173
npm run build      # 生产构建（输出到 dist/）
```

或者双击 `启动事件视界.command`——首次会自动构建，之后直接打开浏览器即玩。

需要支持 WebGL2 的浏览器（Chrome / Edge / Safari 均可）。

## 已实现的物理

- 零测地线光线步进（d²x/dλ² = −1.5·h²·x/r⁵）：阴影、引力透镜、光子环、盘的上下像
- 吸积盘：Novikov–Thorne 温度轮廓、开普勒差速旋转湍流、双相位流动避免噪声剪切
- 相对论多普勒因子 δ + 引力红移 √(1−Rs/r)：亮度 δ³ 聚束、颜色沿黑体谱偏移（EHT M87* 同款效应）
- 相对论喷流：β=0.9 锥形外流、多普勒增亮、湍流结节
- 潮汐撕裂事件（TDE）碎屑流：倾斜平面的蓝白发光带
- 飞船轨道：Paczyński–Wiita 伪牛顿势（保留真实 ISCO 行为），时间膨胀按史瓦西公式精确计算
- 程序星空：黑体色温恒星 + 银河带，全部被透镜实时扭曲
